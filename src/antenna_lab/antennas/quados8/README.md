# Quados 8

Generator `model.py` tworzy cztery symetryczne gałęzie, port różnicowy
i opcjonalny reflektor. Wynik zawiera 48 odcinków osi i 48 węzłów.
Konstrukcja: `docs/quados8-geometry.md`; wymiary: `parameters/quados8_1420mhz.json`.
Generator sprawdza połączenia i wykonalność wymiarów, ale nie uruchamia solvera
i nie deklaruje zysku. Skalowanie z 2450 MHz pozostaje jawnym założeniem.
