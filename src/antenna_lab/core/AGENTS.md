# Rdzeń

Rdzeń zawiera model geometrii, portów, jednostek, walidacji konfiguracji
i zapisu przebiegów. Nie importuje API solvera, GUI ani klas konkretnej anteny.
Geometria konstrukcyjna i dyskretyzacja solvera są osobnymi obiektami.
Przy każdej tablicy zapisuj jednostki, osie i konwencję zespoloną.
