# Parametry

- `reference/` przechowuje wymiary źródłowe bez przeskalowania.
- Aktywna konfiguracja zawiera pełne wartości w SI i jawną historię skalowania.
- Zmiana częstotliwości nie skaluje geometrii automatycznie.
- Nie nadpisuj referencji podczas strojenia. Nowy eksperyment to nowa konfiguracja.
- Obowiązuje `schemas/antenna-config.schema.json`.
- Nie usuwaj oznaczenia założenia 2450 MHz bez potwierdzenia jego pochodzenia.
