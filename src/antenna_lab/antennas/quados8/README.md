# Quados 8

Implementacja generatora: etap M1, jeszcze nie wykonana.

- Konfiguracja startowa: `parameters/quados8_1420mhz.json` od korzenia repozytorium.
- Konstrukcja: `docs/quados8-geometry.md`.
- Wymagania fizyczne i wymiary: `goal.md`.

Generator ma zwracać geometrię czterech gałęzi, idealny port różnicowy
i opis reflektora. Nie generuje sztucznych wykresów ani przewidywanego zysku.
